一、一句话需求

在核心玩法、数据结构、接口全部不变的前提下，把页面从粉色情人节风格整体换皮为万圣节主题，并顺带修掉 3 个影响转化的体验缺口（无 CP 用户看到空榜单即流失 / 解除 CP 后无解释 / 奖励页信息密度过低）。

二、范围

  • 做：视觉换皮：配色、素材、主题文案；交互优化 P0 三项、P1 两项（详见第七节）。
  • 不做：不改后端接口 / 字段 / 分页 / 鉴权；不新增玩法（糖果雨、弹幕、抽奖一律不做）；不动 v1 页面 /ranking/cp；不新增语种（沿用 en / ar，仅加主题文案）。

三、玩法规则（保持不变，作为验收基线）

  • 两名用户结成 CP 关系后互赠「CP 礼物」，按周统计赠送金额（loveValue）排名。
  • 每周一 00:00 开启新周期，周日 23:59 结算；每周 Top 10 获奖，奖励于次周一发放。
  • rank ≤ 3 走领奖台组件（Top3），rank > 3 走普通列表。
  • 榜单分页 limit = 30，触底加载；倒计时以接口返回的 sysTime 校准。
  • CP 关系 status = 0 表示已解除，前端按 unlink 展示。

四、主题与视觉

主题概念：「幽魂 CP 排行榜 / Phantom CP Ranking」——把「CP 亲密度」讲成「灵魂绑定强度」，把「送礼提升亲密度」讲成「为你们的羁绊注入灵魂之火」。

六、本轮已定稿的产品决策（评审重点）

  • 头图满屏：首屏整屏被头图占据，下滑才进正文（不是半屏头图）。
  • Rule 按钮位置：头图下方约 1/4 处、贴右边（原版贴在头图中部偏上，视觉压迫感强）。
  • 领奖台：只保留 2-1-3 底座 + 「TOP 1/2/3」文字表达名次，不加头像上的数字名次角标（信息重复）。
  • 底部 My Rank 条：仅本周榜（This week）展示，切到奖励页 / 上周榜不出现。
  • My Rank 条点击行为：纯信息展示，点击不唤起弹层（原版点击从底部拉起弹层）。
  • My Rank 条文案三态：未上榜 →「距离上榜还差 x」；已上榜 →「距离上一名还差 x」；TOP 1 → 只显名次与分值、不显文案。

文案取值口径：未上榜的「差 x」= 第 10 名分值 − 我的分值；已上榜的「差 x」= 上一名分值 − 我的分值。
