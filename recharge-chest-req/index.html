1. 一句话

把线上现成的「充值宝箱 + 充值月榜」活动页整体换上万圣节主题，

不改核心玩法、奖励规则、接口与发放逻辑，并顺手修掉几个现版体验问题。

2. 现状与目标

项内容
现版线上 /recharge-chest-reward，主题「ROSTAR DRAGON CHEST」巨龙金红
性质纯前端展示层——数据来自 3 个接口，换皮只动 美术 + 样式 + 文案
目标万圣节期间拉动充值；零接口 / 零后端改动；资源可整体替换、可回滚
非目标❌ 不做新玩法 ❌ 不改奖励数值与发奖规则 ❌ 不改接口 ❌ 不做日榜/周榜（现版周榜是死代码）

3. 不能碰的基线

  1. 宝箱线：累计充值达门槛 → 该档 status=1 → 奖励自动发放（无需手动领）
  2. 榜单线：按当月累计充值排名；月末结算 TOP1 = 总充值 7%、TOP2 = 3%
  3. 计入口径（原文照搬，不得改写）：
    • Google Pay / Apple 内购 / 站内三方支付 → 计入
    • 代理商自购 → 不计入
    • 从代理商处买钻石 → 按平台价计入
    • 工资充值 → 不计入
  4. 资格：仅普通用户，Reseller 不可参与
  5. 发奖：自动发放；作弊立即取消并追回

4. 这次要改什么

4.1 四处结构变化

#变化为什么
1新增首屏 Hero，占满整屏、下滑进正文（底部不放下滑提示）现版 banner 与正文挤在一起，层次弱
2新增 TOP1 展示卡 + 结算倒计时现版完全没有倒计时，用户不知道活动何时结算
3规则从「正文内长文本框」→ 首屏左侧按钮进独立规则页（宝箱/榜单两 Tab，正文不折叠）现版 5 条规则把 CTA 顶出首屏
4榜单 Tab 底部两条吸底合并为一条现版「我的排名」+ CTA 叠加，占屏且信息重复
⚠️ 唯一动到布局骨架的地方：现版 banner 高 16.96rem(1272px)，Hero 建议 17.52rem(1314px)。 两者仅差 42px / 5.6%，但头部高度必须跟着改，不是单纯换图。

5. 要修的现版问题

#问题证据方案

2规则长文案顶掉 CTA5 条规则直接铺在奖励下方、无折叠移入独立规则页
3宝箱需点击才切换、默认停在最左无 snap、无默认定位滑动即选中 + 默认定位
